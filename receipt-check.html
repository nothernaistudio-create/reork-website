REORK RECEIPTCHECK / FUNCTIONAL BETA

A workflow said success. Did the records arrive?

Compare what should exist with what actually appeared. Find missing, unexpected, repeated or changed records, then export a clear issue list. Works with spreadsheet exports from many tools without connecting a customer account.

Runs entirely in this browser · files are not uploaded

Beta scope: manual CSV comparison only, not automatic monitoring, not a live payment verification service and not proof that either source export is complete.

1. Expected records

Export the transactions, orders or jobs you believe should have been processed.

Required: id. Optional: amount,currency,status.

2. Delivered records

Export the records from the system where they should have arrived.

Use the same unique ID in both files. Up to 5,000 data rows and 1 MB per file.

What it checks

  • Whether each expected ID appears in the destination
  • Whether a destination record has no matching source
  • Whether either export includes repeated IDs
  • Whether shared amount, currency or status fields differ
  • Exportable exception list for repair and rechecking

What it does not check

It cannot prove that a source export contains every genuine transaction, verify payment settlement, log into a customer's account, identify why a transfer failed or monitor future events. Real automated receipt monitoring would require authorized source and destination connectors, independent checks, security controls and tested alerts.
