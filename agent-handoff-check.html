Free agent-to-agent preflight

Before two agents agree, compare the terms.

One agent requests work. Another proposes to perform it. This tool detects mismatches in the job, price, currency, deadline, countries, deliverable, acceptance criteria, and data-handling rules before a person decides whether to approve.

Both inputs are untrusted claims supplied by the parties. This is NOT a contract, identity check, escrow service, signature verification, proof of honesty or completion, cross-border compliance check, or permission to send money. No external accounts are contacted.

Privacy: validation happens entirely in this browser. REORK does not upload, save, log, or receive these pasted job terms. Avoid using real private contract records in a public demo. Maximum 40,000 characters per input.

Designed for structured agent handoffs; integration into a live agent protocol, API, billing system or escrow would require separate development and security review.
